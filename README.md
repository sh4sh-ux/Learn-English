# NARO Learn English

> 매일의 실제 훈련으로 왕초보에서 C1 목표까지

추가 유료 API나 별도 서버 없이 작동하는 모바일 우선 영어 학습 PWA입니다. 학습 기록은 브라우저의 IndexedDB에 저장되며, 규칙 기반 시나리오 엔진으로 실전 회화를 연습합니다.

## 주요 기능

- 4단계 온보딩과 개인 학습 목표
- 기본 60분(15·30·45·60·90분 선택) Daily 개인 훈련
- 복습 10분, 기초 10분, 쉐도잉 15분, 회화 15분, 읽기·쓰기 10분의 실제 활동 흐름
- 백그라운드·무입력 과대 누적과 중복 실행을 방지하는 활동 타이머
- A0–A1 12주 커리큘럼 구조와 1–2주차 초기 학습 콘텐츠
- Listen → Repeat → Recall → Respond 말하기 4단계 결과 분리 저장
- 실제 기초 표현 30개, 듣기·말하기·예문·문장 퀴즈를 포함한 7단계 학습
- 12개 생활 카테고리의 회화 시나리오(각 4턴)
- CEFR A0–C1 학습 경로와 일반 학습/TOEFL 집중 모드 전환 구조
- 읽기·듣기·말하기·쓰기를 공유하는 통합 콘텐츠 메타데이터
- 의도와 표현 패턴을 이용한 규칙 기반 답변 판정 및 검증 가능한 피드백
- Web Speech API 음성 재생, 지원 브라우저의 음성 인식, 항상 사용 가능한 텍스트 입력
- IndexedDB 스키마 v2 기반 Daily 세션·4영역 활동·학습 기록과 간격 반복 복습 일정
- 새 표현·학습 중·복습 필요·잠정 숙달·장기 기억 확인을 구분하는 숙달 상태
- 실제 기록 기반 통계, JSON 백업·복원, 전체 데이터 초기화
- 설치 가능한 PWA, 버전 캐시, 오프라인 앱 셸 및 학습 콘텐츠

음성 합성과 음성 인식의 품질, 네트워크 사용 여부 및 지원 범위는 브라우저와 운영체제에 따라 다릅니다. 음성 인식 결과는 발음 정확도 점수가 아닙니다.

## 로컬 개발

Node.js 20 이상을 권장합니다.

```bash
npm ci
npm run dev
```

Vite가 표시한 로컬 주소의 `/Learn-English/` 경로에서 앱을 확인합니다.

```bash
npm test
npm run typecheck
npm run build
npm run preview -- --host 127.0.0.1
```

## 데이터와 개인정보

프로필, Daily 세션, 실제 활동 시간, 4영역 기록, 학습·회화 기록과 복습 일정은 이 기기의 IndexedDB에만 저장됩니다. 서버 동기화는 제공하지 않습니다. MY 화면에서 대화문 저장을 끄거나 JSON 백업·복원 및 전체 초기화를 할 수 있습니다. 백업 파일에는 사용자가 입력한 회화 문장이 포함될 수 있습니다. v1 백업은 v2에서 호환 복원됩니다.

## 비용 없이 배포하기

프로덕션 결과물은 `dist/`의 완전한 정적 파일입니다. `vite.config.ts`는 GitHub Pages 저장소 경로인 `/Learn-English/`를 기준으로 설정되어 있습니다.

1. 저장소를 공개하기 전에 민감정보가 없는지 다시 검사하고 저장소 소유자의 승인을 받습니다.
2. GitHub Free에서 Pages를 사용하려면 저장소 공개 조건을 확인합니다. 이 저장소의 공개 여부를 앱이나 스크립트가 자동으로 변경하지 않습니다.
3. `npm ci && npm run build` 후 `dist/`를 GitHub Pages에 배포합니다.
4. 비공개 저장소를 유지해야 한다면, 정적 파일 무료 배포를 지원하는 서비스의 현재 요금·제한과 개인정보 정책을 직접 확인한 후 `dist/`를 배포합니다.

Hash 라우팅을 사용하므로 GitHub Pages에서 하위 화면을 새로고침해도 별도의 서버 재작성 규칙이 필요 없습니다.

## 범위

현재 구현은 PHASE 1 MVP 및 로컬 데이터/PWA 기반 기능입니다. 선택적 온디바이스 생성형 AI는 포함하지 않습니다. 기기별 iPhone Safari·Android Chrome 음성 기능과 설치 UX는 실제 기기에서 별도 확인이 필요합니다.

장기 학습 경로는 Foundation A0, Foundation A1, Everyday A2, Conversation B1, Fluency B2, Advanced C1으로 구성되어 있습니다. 현재 상세 커리큘럼 완료 범위는 A0 1–2주차이며, 3–12주차는 목표와 일일 활동 구조만 준비된 상태입니다. 일정 완료만으로 CEFR 등급을 인증하거나 확정하지 않습니다.

TOEFL 허브는 현재 확장 구조와 통합 기록 화면만 제공하며 시험 문제, 추정 점수 또는 공식 점수 환산을 제공하지 않습니다. 향후 시험 콘텐츠는 최신 ETS 공식 자료로 형식과 채점 기준을 검증한 뒤, 저작권을 침해하지 않는 NARO 자체 제작 자료로 추가해야 합니다.
